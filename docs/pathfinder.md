# Pathfinder implementation

## Requested behavior and source findings

Amethyst requested an R3 navigation menu modeled on Time Stranger, with continuing music and effects, broad non-enemy target coverage, and the bundled pathfinder recording repeating faster near the destination. The player walks; no automatic input or puzzle actions were requested.

Time Stranger reference files were read without changing that project:

- `Core/FieldNavigator.cs`, `UpdateBeep` and `TryGetBeep`: next waypoint placement; constant source gain; destination-distance interval `0.15 + min(distance / 200, 1) * 1.35` seconds.
- `Core/SpatialAudioEngine.cs`: sample-clock looping, configurable start-to-start interval, ordinary 60 ms gaps and 2 ms fades.
- `Handlers/FieldNavigationHandler.cs`, menu input/open/close/start: R3 toggles, left/right categories, up/down distance-sorted entries, A starts, B closes, X stops; game input is captured while field simulation continues.
- `questions_pathfinder_beep.md`: next waypoint, fixed volume at unlimited range, start/end announcements, no spoken distance milestones.

Ocarina source findings:

- `CueMixer` already loads the bundled `pathfinder.wav`; its existing ordinary world markers have a different lifetime from selected-route guidance.
- `CueActors` uses actor initialization/destruction events and verifies pickup/chest/NPC state. Its spatial sources use camera direction and Link distance.
- `SpatialAudio_PublishListener` updates world cues after the listener transform is known. Selected-route audio must use this same mixer and publication boundary.
- `NativeOptions` deliberately pauses gameplay. Navigation needs a separate input owner, model and visible lifetime while reusing its bounded renderer.
- Player collision dimensions come from `ageProperties`: adult radius 18/ceiling height 56, child radius 14/height 40. Native entity collision queries include dynamic background geometry.

## Implementation

`Enhancements/navigation` owns navigation independently of Options. `GameState_Update` calls its input handler after native Options processing, then still calls the game's normal main function. Navigation draws afterward through the existing retained, bounds-checked native display lists. It does not set pause state or send music commands. The ControlDeck input owner plus clearing all native input fields prevents controller, camera and button leakage; held inputs must release on opening/closing. R3 and physical A/B/X follow the requested Time Stranger design; D-pad browses categories/items. Keyboard F8/arrows/Enter/Backspace/Delete supply the same actions. F6 was rejected because it already selects save-state slots.

The search is incremental weighted A* (heuristic weight 4), using native floor support to queue candidates and full native collision to validate accepted connections. Longer trips use candidates derived from the scene's own collision triangles, shared edges, ledges and ladder faces. Shorter trips use a detailed floor grid; an exhausted search tries the other representation once. Both preserve vertical layers, body clearance, ceiling checks and supported ground. Work yields after approximately 6 ms per game update, without the old 128-candidate cap. Memory is bounded at 131,072 nodes and four times that many queued edges. This prioritizes a valid route over a mathematically shortest route. Segments are checked again during guidance. Native OC cylinders/spheres are copied immediately after `CollisionCheck_OC`, honoring compatibility, enabled elements and no-push flags; searches retain no collider pointers. Link's own OC dimensions come from his native cylinder. Moving during search does not restart it: the finished route is joined from Link's current position. Returns from suspension and minor deviations first try to rejoin existing guidance. Native actor lifetimes and current-room changes invalidate selections safely.

Walking checks follow `Actor_UpdateBgCheckInfo`, `BgCheck_EntityRaycastFloor3`, `BgCheck_EntitySphVsWall3`, `BgCheck_EntityCheckCeiling`, and `CollisionCheck_OC`/`CollisionCheck_SetOCvsOC`. Owner IDs accompany every queried polygon. Step sampling is conservative: at most 18 units up and 11 down per sample, no more than eight units between samples. Floor types 2/3 are lava (`func_80838144`), 9 is damaging; properties 5/12 cause respawn/void in `Player_HandleExitsAndVoids`. Deep water and forced-sliding surfaces are excluded from walking routes. Native running jumps and automatic ledge actions now connect supported platforms. Native ladder ascent/descent and climbable-wall ascent are also route connections. Crawlspaces remain approach destinations; crawling, swimming, riding and scene transfers are not modeled as route connections. No player input or movement is synthesized.

Chests use `EnBox_WaitOpen`'s actual local position bounds: -50 < Z < 0, absolute X < 20, absolute Y < 10. Ordinary doors use `EnDoor_Idle`'s absolute local X/Y < 20 and Z < 50. The route positions Link on an approach; facing and interaction remain the player's actions. Generic approach checks reject intervening static or dynamic walls and allow contact with the selected object's own dynamic geometry. Climbable surface endpoints may touch their verified polygon.

The catalog combines event-tracked cue actors, collision-derived exits/climbable surfaces, verified room-specific markers, and additional native switches, signs, rocks, barriers, torches, push blocks and platforms. It excludes enemy/boss categories, destroyed/hidden objects, collected items, opened chests, sign fragments, exploding rupee traps and shooting-gallery markers. Breaking persistent wall actors also removes their entries using the same switch flags their native consumers use. The old cue filter's `<20` chest flag restriction was removed: the native chest consumer uses the full five-bit treasure index. Fixed original-layout markers remain excluded in Master Quest.

Amethyst approved descriptive labels for unnamed objects in `../../pathfinder-questions.md`, retaining real labels wherever available. All 28 descriptions are now present. Existing item and scene text takes priority over those descriptions and is read from the game's established localized banks. The new menu's own wording is centrally stored in `navigation_eng.json`, like the existing English port-menu wording. Distances use approved approximate steps, calibrated from Link's native stride. This is direct distance to the target, not the length of the planned route. The reference's 200-unit cadence distance is retained in native units.

Item mapping follows `EnItem00_Draw` and its pickup consumer in `z_en_item00.c`, after the native drop conversion. Arrow bundles map to the actual `ITEM_ARROWS_SMALL/MEDIUM/LARGE` IDs, and seeds to `ITEM_SEEDS`. A whole heart container must not use Kaleidoscope key 114: `PAUSE_QUEST` speech supplies that key with the collected heart-piece counter. Whole containers and single arrows therefore use their existing port captions from `actorParameters.cpp` and `options_eng.json`. The standalone `tests/navigation/check_resources.py` checks all consumed menu/target keys, these port captions and the 24 native item-name mappings against English, French and German resources.

Selected guidance has a dedicated additional mixer voice, retaining all 128 ordinary slots. Its fixed gain uses the existing persisted pathfinder toggle/volume/reset, native master/effects gain and room reverb. Interval playback follows Time Stranger's sample-clock rule: full clip, remaining interval as silence, 2 ms fades. Interval/position updates retain the playback cursor. Existing fixed pathfinder markers are silenced only during an active route to avoid competing guidance. All other world sounds continue in the menu. The camera compass yields speech focus while the menu is open.
